BOOMR.plugins. PageParams

This plugin is responsible for handling Page Groups, A/B, Custom Timers, Custom Metrics and Custom Dimensions for mPulse.

For information on how to include this plugin, see the Building tutorial.

Prerendering

The following Custom types are affected by Prerendering (and may have their durations reduced by the Activation Start time):

  • UserTiming Marks
  • UserTiming Measures
  • ResourceTiming

The following Custom types are NOT affected by Prerendering:

  • JavaScript variables / functions: Should be updated to take Prerendering into account if desired
  • NavigationTiming: Calculations are done on the Collector

Beacon Parameters

This plugin will add Page Group, A/B, Custom Timers, Metrics and Dimensions to the beacon.

  • h.pg: The Page Group
  • t_other: Custom Timers get added to the beacon as part of t_other. In it, the Custom Timers will be custom[n]|val, separated by commas.
  • custom[n]_st: Start time of a Custom Timer
  • cmet.[name]: Custom Metrics
  • cdim.[name]: Custom Dimensions
